# エリ色

**エリ色**は、開いているエクスプローラーのウィンドウを一覧にまとめ、カードの色で見分けやすくする Windows 向けユーティリティです。

## ダウンロード

[GitHub Releases からエリ色をダウンロード](https://github.com/unisignmasanobutakahashi/eli_iro/releases)

Releases ページで最新のリリースを開き、Assets にある配布ファイルをダウンロードしてください。

## 主な機能

- 開いているエクスプローラーのウィンドウを一覧表示
- 項目を選ぶと、そのエクスプローラーを前面に表示
- カードを右クリックして、項目ごとの色を設定
- 項目をドラッグして、リストの並び順を変更
- 選択したウィンドウをカード色に近い枠と薄い色で強調表示
- 強調中のウィンドウが最小化されたり、別のウィンドウが前面になったりすると枠を非表示
- 「更新」ボタンで一覧を再読み込み

初期表示は名前順です。手動で並び替えると、その順番を保存して次回も使用します。

## 使い方

1. Releases から配布ファイルをダウンロードします。
2. ZIP 形式の場合は、ファイルを展開します。
3. `Eliiro.exe` を起動します。
4. 一覧の項目をクリックして、目的のエクスプローラーを表示します。
5. カード色を変えるときは、項目を右クリックします。
6. 項目をドラッグすると、表示順を変更できます。

## 設定の保存場所

カード色と手動の並び順は、次のファイルに保存されます。

```text
%APPDATA%\Eliiro\colors.ini
```

アプリが設定ファイルを作成できない場合は、実行ファイルと同じフォルダーが保存先になります。

## 強調表示の仕組み

枠と薄い色面は、エリ色が表示するクリック透過のウィンドウです。エクスプローラーのタイトルバー色は変更しません。エクスプローラーへのコード注入、システム設定の変更、常駐フックは行いません。

## 制限事項

Windows 11 のエクスプローラータブは、Windows Shell が個別のウィンドウとして公開しない場合、タブごとには表示されません。
